# Screenshots

PNG captures used by the root `README.md`. Expected filenames:

| File | What it should show |
| --- | --- |
| `home-morning.png` | Home in Morning Mode — light palette, spoken briefing card |
| `home-night.png` | Home at night with a stale export — `STALE`, `NO DATA`, reasons given |
| `health.png` | The Health module and its 7-day trends |
| `sleep.png` | The Sleep module, stage breakdown correctly withheld |
| `settings.png` | Settings — health pipeline and voice diagnostics |
| `insights.png` | Insights generated from the real series |

Once the files are here, uncomment the image table in the root `README.md`.

**A note on what ends up in the picture.** These screenshots contain real heart
rate, HRV and sleep values, and the source footer names the watch they came
from. The repository is public; the numbers in it do not have to be. Capture a
session you are happy to publish, or blur them before committing.
